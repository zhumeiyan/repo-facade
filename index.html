Repo Facade

给任意仓库生成一套活的状态立面——扫一眼就懂，在 README 里真的会动，能被 git 版本化。

python3 facade.py --repo owner/name --out ./assets

它跟素材库贴图的区别

  • 零 JavaScript：动画是 SVG 内嵌 CSS @keyframes。GitHub 会剥掉 <script>，所以这是动画能在 README 里真的播放的唯一办法。
  • 身份连续：形象由仓库标识的哈希确定性派生，同一仓库永远同一张脸，不每次重画。
  • 无面：不画人脸、拟人动物、表情包。
  • 母题来自结构：渗流 / 枝晶 / 晶格，由仓库自身签名决定——不是通用科技背景。
  • 可回滚：SVG / HTML / MD 全是文本，能 diff、能回退。
